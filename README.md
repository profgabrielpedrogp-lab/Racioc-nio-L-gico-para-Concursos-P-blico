# Diagrama de Venn – Aula Preparatória para Concursos

Material de estudo interativo sobre **Diagrama de Venn** e Raciocínio Lógico Matemático voltado para concursos públicos.

## 👨‍🏫 Professor
**Professor Gabriel Pedro**

## 📚 Conteúdo Incluído
1. Teoria dos Conjuntos e Conceito de Universo (U)
2. Operações Básicas de Conjuntos (União, Interseção, Diferença, Complementar)
3. Fórmulas de Contagem para 2 e 3 Conjuntos
4. Passo a Passo do Método de Resolução
5. Exemplo Prático Resolvido com 3 Conjuntos
6. Diagramas Lógicos (Todo, Algum e Nenhum)
7. Dicas Estratégicas para Provas (Cebraspe, FGV, FCC, etc.)
8. Exercícios Comentados com Gabarito Interativo
